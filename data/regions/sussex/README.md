# Sussex controlled import package

This directory is a preparation area only. It contains schemas and empty templates, not a published dataset. No service records, contact details, council submission routes or model-memory data are included. `SUSSEX-DATA-001` remains open.

- `source/`: supplied authoritative source files, currently empty except for its control note.
- `revisions/`: immutable accepted revisions, currently empty except for its control note.
- `quarantine/`: invalid or unresolved inputs, never published.
- `reports/`: validation and reconciliation evidence.
- `templates/`: controlled JSON, CSV and workbook templates.
